# agentic-shop

Multi-agent AI shopping experience — the UI is an output of the agent, not the place where
the agent operates. Practice project for agentic frontend patterns.

- `PRD.md` — product requirements (v0.1 MVP)
- `DECISIONS.md` — locked architecture decisions (binding)
- `AGENTS.md` — guide for coding agents working in this repo

## Status

Phase 1: backend scaffold (LangGraph agent graph, catalog, tools, UI DSL, SSE API).
Frontend lands later on top of a Next.js boilerplate.

MVP scenario: "Help me find the best headphones for long flights under $200."
